# GODSEED Android: separate supported Gradle/WebView evaluation host

**Status:** a new independent development branch from `feat/godseed-medieval-skyworld-v1`, designed to avoid replacing the existing experimental SDK-free APK or overwriting Codex's work. `android/build_apk.py` remains untouched.

## Design
- App identity `io.godseed.one`, Android API 26 minimum; currently compiled with Android API 35 / AGP 8.7.3 / Gradle 8.9 / JDK 17.
- Entrypoint `file:///android_asset/index.html`: preserves the existing localStorage origin and save key `godseed-one-small-life-v1`. Rebuild with `python build.py` **before** Gradle compilation.
- Android's built-in WebView runs the unchanged offline JavaScript/Canvas simulation and original pixel art. No Internet permission, remote content, ads or 3D engine.
- Uses a WebChromeClient file picker for existing JSON world backups, and calls the game's `GodseedHostLifecycle.pause/resume` callbacks for save/resume on activity lifecycle.
- Native-only local storage manager is hidden in ordinary browser preview and old SDK-free APK. Optional imports are selected via Android Storage Access Framework, explicitly approved in a native dialog, and held under app-private `files/optional-lore`.
- `StorageQuota` enforces intended decimal 5 GB optional and 6 GB nominal combined boundaries with a free-space reserve; the measured host APK bytes are a **lower-bound estimate**, not total installed core usage or 1 GB of real content. No space preallocation.
- `PackStore` first supports **small lore ZIP packs only (8 MiB compressed and 2 MiB lore text)**. This is deliberate until Android low-RAM and I/O testing is available. `manifest.json` and `lore.json` required, SHA-256 over uncompressed lore, limited entries/fields/size, no unpacking arbitrary ZIP paths, staged atomic install, user-confirmed removal. No script evaluation from packs. Region lore is shown only for region IDs in Nim's discovered list.
- All older saves and the main simulation remain unchanged. The debug keystore is generated by the Android tooling and **is not** a stable signing identity. Installing it over an app signed with an unrelated key may require exporting saves before uninstalling.

## Native verification
```sh
sh tests/native/run-storage-checks.sh
python build.py
gradle -p android/gradle :app:assembleDebug --no-daemon
```
Or inspect the `GODSEED native Android evaluation` GitHub Actions workflow for compiled APK evidence.

`StorageQuotaChecks.java` tests byte boundaries and low-space behavior without an SDK. `test_lore_pack_generator.py` verifies reproducible example archive digests.

Optional example pack:
```sh
python scripts/make_sample_lore_pack.py dist/mossveil-sample.gspack
```
In the **Gradle host**, choose **Local packs → Import** and select that `.gspack` with Android's document picker. After Nim discovers R03 or R06, the region's optional lore is viewable from that panel.

## Known limitations and release blockers
- Real Android device installation, input, file picker, activity lifecycle, storage pressure, 2–3 GB-RAM memory use and signing continuity remain **NOT VERIFIED** until physically tested.
- The 1 GB intended core content and 5 GB optional capacity are **budgets**, not filled with dummy bytes. The current demo bundle remains tiny.
- File-origin WebView is not intended for remote or untrusted HTML. The bridge is only enabled on packaged assets and the host blocks remote HTTP/S loads and navigation.
- The Android Gradle host and native packs are separate from the SDK-free prototype. Do not silently replace or merge this host to `main` before review and hardware QA.
- Updating already-installed packs, huge binary asset streaming, APK release signing and 20-minute physical stability checks are future work.
